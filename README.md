Bioinformatics Mini-Projects Portfolio
Anam | BS Biotechnology, Virtual University of Pakistan
A collection of small bioinformatics analyses completed as part of my preparation for graduate study in Bioinformatics/Data Analysis.
Projects
1. Physicochemical Analysis of Human Insulin — Analyzed protein properties (molecular weight, stability, hydropathicity) using ExPASy ProtParam.
2. 3D Structure Visualization of Human Insulin — Visualized the hexameric structure of Human Insulin (PDB ID: 4EYD) using the RCSB PDB Mol* viewer.
3. Multiple Sequence Alignment & Phylogenetic Analysis of BCR-ABL1 Fusion Variants — Aligned four BCR-ABL1 fusion transcript variants (associated with leukemia) using Clustal Omega, identifying a conserved ABL1-derived region and clustering patterns among variants.
Full details and results for each project are documented in the attached portfolio file.
4. DNA Sequence Analyzer — Built a Python tool that counts nucleotide base composition (A, T, G, C), calculates GC content, and validates DNA sequences for invalid characters. Applies core programming concepts (loops, conditionals, flag variables) to a fundamental bioinformatics task used in sequence quality control and organism classification.
